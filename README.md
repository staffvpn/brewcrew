# Brew Crew

Telegram Mini App: idle-симулятор кофейни с абсурдными инцидентами.

Сейчас это прототип в одном файле `index.html`, без сборки. Cloudflare Pages: framework preset None, build command пустая, output directory `/`.

Токен бота в репозиторий не кладём: он будет в секретах Cloudflare, когда появится сервер.
