# Интерьеры Brew Crew

Игровые спрайты созданы в PixelLab. Референсами послужили существующие стили «Домашний», «Снежный», «Фика», «Флагман» и «Не спим», домашняя мебель и [золотая кофемашина](../season-gold-machine.md).

Карточки «Люкса» показывают верхнюю часть стандартного игрового зала с установленным интерьером. Стены с новым рисунком сгенерированы целиком. Передняя стойка с витриной и кассой и задняя стойка с кофемашиной используют собственные фасады из отдельных секций. Размеры полок, окон и стоек задаёт игровая сцена.

В `pixellab-prompts.json` записаны исходные промпты, seed и идентификаторы генераций, где они доступны.
